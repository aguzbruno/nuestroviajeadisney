# Viaje Mágico — Disney · Universal · NYC

Sitio interactivo del viaje familiar (sep–oct 2026).

## Desarrollo

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Qué incluye

- Gate “¿Quién sos?” con personajes Disney
- Home scroll-story del cronograma (18 días)
- Calendario, vuelos, hoteles, parques Disney/Universal
- Página HHN (`/universal/halloween`)
- Shopping Orlando, NYC (166A Chelsea), álbum de stickers, packing

Datos tipados en `src/data/`.
